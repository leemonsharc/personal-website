whiskerBBS + financier

12/06/2025

over the past month, i've been working on two projects.

i really apologize for not recording any logs, but i've been busy.

the first of the two projects is whiskerBBS, a cat-themed bulletin board system.

it is heavily inspired by my adorable kitty cat winter!

if you haven't noticed by now, i love cats and retro stuff (two of my favorite things)

whiskerBBS is built in python, and uses a telnet server to allow users to connect to it.

it will have a

- message board, where users can post and read messages

- moderated file sharing system

- and simple text-based & ASCII games!

the second project is financier, a finance calculator built in python.

it will allow users to calculate things such as loan payments, compound interest, and inflation over time.

not as fun, but still useful :D

i plan to release both projects in early-to-mid-2026!
